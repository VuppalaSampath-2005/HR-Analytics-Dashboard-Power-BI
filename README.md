HR Analytics Dashboard – Power BI

Developed an interactive HR Analytics Dashboard using Power BI to analyze 1,470 employee records and identify workforce trends, employee demographics, departmental performance, and attrition patterns.

Key Features:
 Analyzed employee demographics and workforce distribution.
 Cleaned and transformed data using Power Query.
 Created data models and DAX measures.
 Designed interactive KPI cards, charts, and slicers.
 Analyzed attrition based on department, job role, age, overtime, and business travel.

Tools: Power BI, Power Query, DAX, Data Modeling, Data Visualization.
